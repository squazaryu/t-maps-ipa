# T-Maps для Feather

Источник неподписанной T-Maps для установки со своим сертификатом.

## Добавить в Feather

В Feather открыть **Источники (Sources) → +** и вставить:

```text
https://raw.githubusercontent.com/squazaryu/t-maps-ipa/refs/heads/main/source.json
```

В каталоге появится T-Maps с буквой T на фоне карты. Скачать приложение, подписать
своим сертификатом и установить как обновление с прежним Bundle ID `ru.tumowuh.tmaps`.
Сертификаты, пароли, приватные ключи и provisioning profiles сюда не загружаются.

## Текущий пакет

**0.9.2 (20), минимум iOS 26, unsigned technical candidate.**

[Сборка и Assets](https://github.com/squazaryu/t-maps-ipa/releases/tag/v0.9.2-rc.20-public.1)

Публичная ревизия упаковки 1: удалены отладочные записи с локальными путями и
локальные file-URL из метаданных происхождения. Все 49 секций Mach-O, данные загрузчика,
экспортируемые символы, остальные ресурсы и геоданные сохранены без изменений.
Версия и build приложения не менялись. Сводка и контрольная сумма — в `release.json`,
проверка эквивалентности — `publication-proof.json`.

Физическая приёмка GPS, голоса, фона, энергии и FPS остаётся открытой. Это технический
кандидат, а не финально принятый релиз. Нет расписаний и пробок; полная офлайн-подложка
и городская оптимизация по тени не объявляются готовыми.

## Обновления

При выпуске следующей IPA обновляются `release.json`, `SHA256SUMS.txt` и `source.json`.
Адрес источника остаётся прежним. После обновления источников в Feather новая версия
появится в каталоге. Автоматическая публикация из процесса разработки не настроена.
