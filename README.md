# T-Maps IPA

Закрытый репозиторий для личной установки T-Maps через Feather.
Здесь хранятся сведения о сборках; сами IPA находятся во вложениях **Releases**, вне истории Git.

## Текущая сборка

**T-Maps 0.9.2 (20), unsigned, технический кандидат.** Минимум iOS 26.

- [Открыть страницу сборки](https://github.com/squazaryu/t-maps-ipa/releases/tag/v0.9.2-rc.20)
- [Скачать IPA](https://github.com/squazaryu/t-maps-ipa/releases/download/v0.9.2-rc.20/T-Maps-0.9.2-rc-20-unsigned.ipa)
- Размер: 396 937 718 байт.
- Bundle ID: `ru.tumowuh.tmaps`.
- SHA-256: `0ce4199b87140de5a84dec0fe36533ee879f694b46e63bd1f0c955e3b529bed5`.

## Установка на iPhone

1. Войти в GitHub под учётной записью с доступом к этому репозиторию.
2. Открыть страницу сборки в Safari, в **Assets** скачать файл `.ipa` в «Файлы».
3. Импортировать IPA в Feather, подписать своим сертификатом и установить обновлением с прежним Bundle ID.

Из-за закрытого доступа автоматическое чтение каталога из Feather не настроено.
Токены авторизации в ссылки не добавляются. Подпись остаётся на устройстве владельца;
сертификаты, приватные ключи и provisioning profiles здесь не хранятся.

## Подготовленный источник Feather

В `source.json` подготовлен каталог AltStore с T-Maps 0.9.2 (20), а в
`assets/t-maps-icon.png` — актуальная иконка с буквой T на карте. Пока репозиторий закрыт,
Feather без авторизации не сможет загрузить ни каталог, ни IPA; вставлять токены в ссылку
не требуется и не следует. Публичная версия источника потребовала бы отдельного решения
владельца, так как IPA стала бы доступна всем.

Постоянный адрес файла после разрешения доступа:
`https://raw.githubusercontent.com/squazaryu/t-maps-ipa/refs/heads/main/source.json`.
При публикации новой версии нужно обновить в каталоге version/build/date, размер и ссылку
на IPA в GitHub Releases; адрес самого источника при этом не меняется.

## Содержимое и статус

В 0.9.2 добавлены поиск кафе и других категорий, ограниченные запросы по описанию,
единые значки категорий в списках, карточках и на карте; исправлены ограничения поиска «рядом со мной».
Это проверенный технический кандидат, **не принятый физический релиз**.
Проверки GPS, озвучивания, фона, энергии и FPS на физическом iPhone остаются открытыми и поставлены на паузу владельцем.
Известные ограничения: нет расписаний и пробок; нет гарантии корректного неизвестного входа;
полная офлайн-подложка, городская маршрутизация по тени и продвинутый локальный ИИ не объявляются готовыми.

Сведения об открытых геоданных, атрибуция OpenStreetMap и уведомления о лицензиях зависимостей
сохранены внутри приложения. Исходники приложения в этот репозиторий не загружаются.
